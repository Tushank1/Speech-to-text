# 🗣️ Speech-to-Text

A lightweight and beginner-friendly Python project that captures real-time audio from your microphone and transcribes it into text using the **SpeechRecognition** library.

---

## 🚀 Features

- 🎤 Real-time speech recognition
- 📝 Converts spoken words to text
- ⚙️ Easy to set up and run locally
- 🐍 Built entirely with Python

---

## 📦 Requirements

Make sure you have Python 3.x installed. Then install dependencies using:

```bash
pip install -r requirements.txt
